# Avatar

**Avatar** یک تونل لبه‌ای روی Cloudflare Workers/Pages با پنل مدیریت فارسی و راست‌به‌چپ است: ساخت لینک اشتراک برای همهٔ برنامه‌های رایج، مدیریت آی‌پی‌های بهینه، پراکسی زنجیره‌ای، اعلان تلگرام و آمار مصرف، همه از یک فایل.

## ویژگی‌ها
- پشتیبانی از VLESS، Trojan و Shadowsocks روی WebSocket، gRPC و XHTTP
- پنل مدیریت کامل فارسی (درون همین فایل؛ بدون وابستگی به میزبان بیرونی)
- اشتراک خودکار برای Clash/Mihomo، Sing-box، Surge، Quantumult X، Loon و Base64، همراه کد QR
- آی‌پی بهینهٔ تصادفی یا فهرست سفارشی، API آی‌پی و تولیدکنندهٔ اشتراک بیرونی
- پراکسی معکوس و زنجیره‌ای SOCKS5 / HTTP / HTTPS / TURN / SSTP با آزمایش اتصال
- گزارش رویدادها، اعلان تلگرام و نمایش مصرف روزانهٔ Cloudflare

## راه‌اندازی سریع (Workers)
1. یک Worker تازه بسازید و محتوای `_worker.js` را در ویرایشگر جای‌گذاری کنید.
2. در **Settings ← Variables and Secrets** متغیر `ADMIN` را با رمز مدیر بسازید.
3. یک فضای نام KV بسازید و با نام اتصال `KV` به Worker وصل کنید.
4. یک دامنهٔ سفارشی وصل کنید و نشانی `https://دامنه-شما/admin` را باز کنید.

برای **Pages** کل پوشه را به‌صورت ZIP بارگذاری کنید و همان متغیر و اتصال KV را تنظیم کنید.

## متغیرهای محیطی
| متغیر | الزامی | نمونه | توضیح |
| :--- | :---: | :--- | :--- |
| `ADMIN` | ✅ | `MyStrongPass` | رمز ورود به پنل |
| `KEY` | ❌ | `my-secret` | مسیر اشتراک سریع؛ با `/my-secret` اشتراک دریافت می‌شود |
| `UUID` | ❌ | `90cd4a77-141a-43c9-991b-08263cfe9c10` | ثابت‌کردن UUID (فقط قالب UUIDv4) |
| `PROXYIP` | ❌ | `proxy.example.com:443` | آی‌پی پراکسی معکوس سراسری |
| `URL` | ❌ | `https://example.com` | سایت پوششی صفحهٔ اصلی (یا `1101`) |
| `HOST` | ❌ | `a.example.com,b.example.com` | دامنه‌های لینک‌ها |
| `PATH` | ❌ | `/ws` | مسیر پیش‌فرض گره‌ها |
| `GO2SOCKS5` | ❌ | `*.example.com` | دامنه‌هایی که همیشه از پراکسی زنجیره‌ای می‌گذرند |
| `DEBUG` | ❌ | `true` | فعال‌سازی گزارش اشکال‌زدایی |
| `OFF_LOG` | ❌ | `true` | خاموش‌کردن ثبت گزارش در KV |
| `BEST_SUB` | ❌ | `true` | فعال‌سازی نقش تولیدکنندهٔ فهرست بهینه |
| `PRELOAD_RACE_DIAL` | ❌ | `true` | شماره‌گیری رقابتی با پیش‌بارگذاری DNS |
| `TCP_CONCURRENT_DIAL` | ❌ | `2` | تعداد اتصال هم‌زمان TCP |
| `PROXY_CONCURRENT_DIAL` | ❌ | `1` | تعداد اتصال هم‌زمان پراکسی |

## پارامترهای مسیر
```
/proxyip=proxy.example.com
/socks5=user:pass@127.0.0.1:1080
/socks5://user:pass@127.0.0.1:1080   (سراسری)
/http=user:pass@127.0.0.1:8080
/trojan=1.1.1.1:1234                 (fallback)
```
